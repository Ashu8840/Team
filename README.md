# MERN CRUD Application

A simple CRUD (Create, Read, Update, Delete) application built using the **MERN Stack** (MongoDB, Express.js, React.js, Node.js).

## 🚀 Features
- Create new records
- Read & display all records
- Update existing records
- Delete records
- Responsive UI
- REST API integration

## 🛠️ Tech Stack
- **Frontend:** React.js, Axios, Tailwind CSS (or CSS/Bootstrap)
- **Backend:** Node.js, Express.js
- **Database:** MongoDB (with Mongoose)
- **Other Tools:** Nodemon, Git, GitHub
